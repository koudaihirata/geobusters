## ジオバスターズ（GeoBusters）

ジオバスターズは、現在地の周辺スポットを手がかりにAIがカードを生成し、オンライン対戦で遊べるリアルタイムカードゲームです。  
ルームに集まってゲームを開始すると、スポット名から作られたオリジナルカードが配られ、攻撃・防御・回復などのアクションを選んで勝敗を競います。

### 主な特徴
- 位置情報（Geolocation）を使った“その場限り”のカード生成
- AIによるカード名・効果・画像の自動生成
- WebSocketによるリアルタイム対戦（ルーム／ゲームの2フェーズ）
- ホストのみゲーム開始、メンバー表示、ログ表示

### 使い方（概要）
1. ルームに入室してメンバーを揃える
2. ホストがゲーム開始
3. 生成されたカードで対戦
