# フロントエンド（GeoBusters）

ジオバスターズのUIを担当します。  
ルームでの待機やメンバー表示、ゲーム画面での手札・HP・ターンの表示まで、プレイヤーの体験をそのまま形にする領域です。

## ここでやっていること
- ルーム参加とメンバー表示
- ゲーム開始の待機UIとロード表示
- AIカードの受信と表示
- 手札やターン表示などのゲームUI

## 苦労した点
- WebSocketでの状態同期（RoomとGameで状態がズレやすい）
- AIカードの受信タイミングと表示の整合性
- 生成画像の表示（トリミングや余白処理）

## ここまで読んでくれた方へ
UIは「何が起きているか分かること」を優先しています。  
ロード中の表示やログは、ユーザーの不安を減らすために意図的に入れています。
